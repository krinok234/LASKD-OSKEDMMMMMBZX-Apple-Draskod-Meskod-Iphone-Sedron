# Инструкция по установке

## Вариант 1: Быстрый запуск (без Tauri)

Если хотите просто посмотреть сайт в браузере:

```bash
npm start
```

Откройте браузер: http://localhost:3000

## Вариант 2: Полная установка с Tauri (десктопное приложение)

### Шаг 1: Установите Rust

1. Скачайте установщик: https://rustup.rs/
2. Запустите `rustup-init.exe`
3. Следуйте инструкциям (выберите вариант 1 - стандартная установка)
4. После установки **перезапустите терминал**

### Шаг 2: Проверьте установку

```bash
rustc --version
cargo --version
```

Должны увидеть версии Rust и Cargo.

### Шаг 3: Установите дополнительные зависимости для Windows

```bash
# Установите WebView2 (если еще не установлен)
# Обычно уже есть в Windows 10/11
```

### Шаг 4: Запустите приложение

```bash
npm run dev
```

Первый запуск займет 5-10 минут (компиляция Rust).

### Шаг 5: Соберите готовое приложение

```bash
npm run build
```

Готовый .exe файл будет в папке: `src-tauri/target/release/`

## Решение проблем

### Ошибка "cargo.exe not found"
- Убедитесь, что Rust установлен: `rustc --version`
- Перезапустите терминал после установки Rust
- Проверьте PATH: `echo %PATH%` (должен содержать `.cargo\bin`)

### Ошибка "WebView2 not found"
- Скачайте WebView2: https://developer.microsoft.com/microsoft-edge/webview2/

### Долгая компиляция
- Это нормально для первого запуска (5-10 минут)
- Последующие запуски будут быстрее

## Что дальше?

После запуска вы увидите красивый интерфейс донат-сайта с:
- Тремя категориями привилегий
- Формой покупки
- Системой промокодов
- Каруселью игроков

Для интеграции с реальной платежной системой отредактируйте функцию `handlePayment()` в `script.js`
